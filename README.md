# STM32 两轮平衡车

本项目是基于 STM32F103C8 的两轮平衡车控制程序。程序使用 MPU6050 估计车身俯仰角，结合双轮编码器反馈，通过直立、速度和转向控制环驱动左右电机。系统提供 OLED 状态显示、实体按键启停，以及蓝牙摇杆控制和参数调整。

当前版本聚焦双轮平衡与遥控。寻迹功能属于后续扩展方向，尚未集成到本仓库固件中。

## 项目功能

- **姿态估计**：融合加速度计与陀螺仪数据，实时计算车身俯仰角。
- **双轮平衡**：直立环根据目标角度和当前姿态生成平均电机输出。
- **速度控制**：编码器测得左右轮速度，速度环通过调整目标俯仰角控制前后运动。
- **差速转向**：转向环根据左右轮速度差分配两侧电机输出。
- **交互控制**：通过 OLED 查看运行数据，使用实体按键启停，通过蓝牙摇杆设置运动目标、滑块调整控制参数。

## 系统架构

~~~text
                    ┌────────── MPU6050 ──────────┐
                    │      加速度与角速度采样      │
                    └────────────┬─────────────────┘
                                 ▼
                            姿态互补滤波
                                 │ 俯仰角
                                 ▼
蓝牙速度目标 ──> 速度 PID ──> 目标角度 ──> 直立 PID ──> 平均 PWM ──┐
                                                                    ├─> 左右电机
蓝牙转向目标 ──> 转向 PID ───────────────────────> 差分 PWM ────┘
                    ▲
                    └──────── 左右轮编码器速度反馈
~~~

控制任务由 TIM1 周期中断调度：姿态采样、直立控制和电机更新按约 **100 Hz** 执行；编码器测速、速度环和转向环按约 **20 Hz** 执行。TIM2 提供双路 PWM，按工程的 72 MHz 时钟配置计算，载波频率约为 **20 kHz**。

## 控制方法

### 姿态估计

MPU6050 驱动一次读取 14 字节惯性数据。固件使用 X、Z 轴加速度计算俯仰角参考值，并对 Y 轴角速度积分，再以互补滤波合成车身角度：

~~~text
θacc  = −atan2(AX, AZ) × 180/π + 0.85°
ωgyro = (GY + 32) × 2000/32768             [°/s]
θ[k]  = 0.01 × θacc + 0.99 × (θ[k−1] + 0.01 × ωgyro)
~~~

其中 0.85°、32 和滤波权重为当前固件参数。MPU6050 初始化量程为加速度 **±16 g**、角速度 **±2000 °/s**。

### 串级 PID 与电机分配

速度环以左右轮平均速度为反馈，输出直立环的目标角度；直立环输出平均 PWM。转向环以左右轮速度差为反馈，输出差分 PWM。两路电机命令按下式合成：

~~~text
vavg   = (vL + vR) / 2
vdiff  = vL − vR
θref   = SpeedPID(vref − vavg)
ub     = −AnglePID(θref − θ)
ut     = TurnPID(Δvref − vdiff)
PWM_L  = limit(ub + ut/2, −100, 100)
PWM_R  = limit(ub − ut/2, −100, 100)
~~~

PID 使用位置式计算，并对积分状态和输出进行限幅。当前固件中的控制参数如下，可通过蓝牙滑块在线调整：

| 控制环 | Kp | Ki | Kd | 输出范围 |
| --- | ---: | ---: | ---: | ---: |
| 直立环 | 5 | 0.1 | 5 | ±100 PWM |
| 速度环 | 2 | 0.05 | 0 | ±20° 目标角 |
| 转向环 | 4 | 3 | 0 | ±50 差分 PWM |

车身估计俯仰角超过 **±50°** 时，运行标志清零，控制分支将两路电机命令设为 0。

## 蓝牙控制

USART2 接收方括号包裹、逗号分隔的 ASCII 指令。以下是固件已处理的两类指令：

| 指令示例 | 作用 |
| --- | --- |
| [joystick,0,25,25,0] | 摇杆的 LV 设置速度目标，RH 设置转向目标；固件将两者分别除以 25 |
| [slider,AngleKp,5.0] | 设置直立环 Kp；同类字段还包括 AngleKi、AngleKd、SpeedKp/Ki/Kd、TurnKp/Ki/Kd 和 Offset |

## 编译与使用

1. 使用 **Keil µVision 5** 打开 [Project.uvprojx](Project.uvprojx)。工程目标器件为 STM32F103C8，使用 STM32F10x 标准外设库。
2. 编译并通过配置的调试器下载固件。若需要独立 HEX 文件，可在 Keil 工程选项中启用 HEX 生成。
3. 接好主控、MPU6050、编码器、电机驱动和显示模块后，先架空车轮检查姿态角、电机方向及编码器读数。
4. 将车身扶至直立位置，使用 **PB1 对应的按键**切换运行状态；OLED 显示角度、轮速和控制参数。
