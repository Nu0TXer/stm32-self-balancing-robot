# STM32 两轮平衡车

本项目是基于 STM32F103C8 的两轮平衡车控制程序。程序使用 MPU6050 估计车身俯仰角，结合双轮编码器反馈，通过直立、速度和转向控制环驱动左右电机。系统提供 OLED 状态显示、实体按键启停，以及蓝牙摇杆控制和参数调整。

当前版本聚焦双轮平衡与遥控。寻迹功能属于后续扩展方向，尚未集成到本仓库固件中。

## 项目定位

本项目面向 STM32 嵌入式控制学习与两轮平衡车系统开发，重点展示从传感器采集、姿态估计、串级反馈控制到电机执行的完整实现链路。当前仓库包含 Keil 工程、STM32F10x 标准外设库接口代码和主要硬件驱动，适合用于控制算法分析、底盘调试和后续功能扩展。

当前版本的功能边界如下：

- 已实现姿态估计、直立控制、速度控制、差速转向、编码器测速、OLED 显示、按键启停和蓝牙参数交互。
- 寻迹传感器接入、线路位置估计和寻迹控制尚未实现，属于后续开发计划。
- 控制频率由定时器配置推算；平衡时间、扰动恢复、速度精度等性能需要通过实车实验测量。

## 项目功能

- **姿态估计**：融合加速度计与陀螺仪数据，实时计算车身俯仰角。
- **双轮平衡**：直立环根据目标角度和当前姿态生成平均电机输出。
- **速度控制**：编码器测得左右轮速度，速度环通过调整目标俯仰角控制前后运动。
- **差速转向**：转向环根据左右轮速度差分配两侧电机输出。
- **交互控制**：通过 OLED 查看运行数据，使用实体按键启停，通过蓝牙摇杆设置运动目标、滑块调整控制参数。

## 系统架构

~~~text
                    ┌────────── MPU6050 ──────────┐
                    │      加速度与角速度采样      │
                    └────────────┬─────────────────┘
                                 ▼
                            姿态互补滤波
                                 │ 俯仰角
                                 ▼
蓝牙速度目标 ──> 速度 PID ──> 目标角度 ──> 直立 PID ──> 平均 PWM ──┐
                                                                    ├─> 左右电机
蓝牙转向目标 ──> 转向 PID ───────────────────────> 差分 PWM ────┘
                    ▲
                    └──────── 左右轮编码器速度反馈
~~~

控制任务由 TIM1 周期中断调度：姿态采样、直立控制和电机更新按约 **100 Hz** 执行；编码器测速、速度环和转向环按约 **20 Hz** 执行。TIM2 提供双路 PWM，按工程的 72 MHz 时钟配置计算，载波频率约为 **20 kHz**。

## 控制方法

### 姿态估计

MPU6050 驱动一次读取 14 字节惯性数据。固件使用 X、Z 轴加速度计算俯仰角参考值，并对 Y 轴角速度积分，再以互补滤波合成车身角度：

~~~text
θacc  = −atan2(AX, AZ) × 180/π + 0.85°
ωgyro = (GY + 32) × 2000/32768             [°/s]
θ[k]  = 0.01 × θacc + 0.99 × (θ[k−1] + 0.01 × ωgyro)
~~~

其中 0.85°、32 和滤波权重为当前固件参数。MPU6050 初始化量程为加速度 **±16 g**、角速度 **±2000 °/s**。

### 串级 PID 与电机分配

速度环以左右轮平均速度为反馈，输出直立环的目标角度；直立环输出平均 PWM。转向环以左右轮速度差为反馈，输出差分 PWM。两路电机命令按下式合成：

~~~text
vavg   = (vL + vR) / 2
vdiff  = vL − vR
θref   = SpeedPID(vref − vavg)
ub     = −AnglePID(θref − θ)
ut     = TurnPID(Δvref − vdiff)
PWM_L  = limit(ub + ut/2, −100, 100)
PWM_R  = limit(ub − ut/2, −100, 100)
~~~

PID 使用位置式计算，并对积分状态和输出进行限幅。当前固件中的控制参数如下，可通过蓝牙滑块在线调整：

| 控制环 | Kp | Ki | Kd | 输出范围 |
| --- | ---: | ---: | ---: | ---: |
| 直立环 | 5 | 0.1 | 5 | ±100 PWM |
| 速度环 | 2 | 0.05 | 0 | ±20° 目标角 |
| 转向环 | 4 | 3 | 0 | ±50 差分 PWM |

车身估计俯仰角超过 **±50°** 时，运行标志清零，控制分支将两路电机命令设为 0。

## 蓝牙控制

USART2 接收方括号包裹、逗号分隔的 ASCII 指令。以下是固件已处理的两类指令：

| 指令示例 | 作用 |
| --- | --- |
| [joystick,0,25,25,0] | 摇杆的 LV 设置速度目标，RH 设置转向目标；固件将两者分别除以 25 |
| [slider,AngleKp,5.0] | 设置直立环 Kp；同类字段还包括 AngleKi、AngleKd、SpeedKp/Ki/Kd、TurnKp/Ki/Kd 和 Offset |

## 编译与使用

1. 使用 **Keil µVision 5** 打开 [Project.uvprojx](Project.uvprojx)。工程目标器件为 STM32F103C8，使用 STM32F10x 标准外设库。
2. 编译并通过配置的调试器下载固件。若需要独立 HEX 文件，可在 Keil 工程选项中启用 HEX 生成。
3. 接好主控、MPU6050、编码器、电机驱动和显示模块后，先架空车轮检查姿态角、电机方向及编码器读数。
4. 将车身扶至直立位置，使用 **PB1 对应的按键**切换运行状态；OLED 显示角度、轮速和控制参数。

## 未来优化方向

后续优化按照“先保证测量和安全，再提升控制性能，最后扩展自主功能”的顺序进行。

### 1. 传感器标定与参数固化

- 增加上电静止标定，自动估计陀螺仪零偏和加速度计静态均值。
- 根据 IMU 实际安装方向校准机械直立角，替换固定的 `GY += 32` 和 `AngleAcc += 0.85` 补偿方式。
- 核对编码器每转计数、减速比、轮径和左右轮方向，将速度换算系数整理为带单位的配置参数。
- 记录静态漂移、温度变化和低速计数噪声，为滤波和 PID 整定提供数据。

### 2. 姿态估计与控制器优化

- 根据实测采样周期更新互补滤波积分时间，避免固定 `0.01 s` 与实际调度周期不一致。
- 在输出饱和时采用条件积分或回算抗积分饱和，减少大姿态误差恢复后的过冲。
- 对速度目标、转向目标和目标俯仰角增加斜坡限制，降低指令突变对直立环的冲击。
- 根据角度、角速度、轮速和 PWM 的同步日志重新整定直立、速度和转向三个控制环。
- 评估基于陀螺仪角速度阻尼、状态反馈或 LQR 的替代方案，但必须以已标定的模型和对照实验为基础。

### 3. 实时性与软件结构优化

- 测量 TIM1 控制中断的最坏执行时间、周期抖动和潜在漏周期。
- 将软件 I²C 读取、显示刷新和控制计算进行任务分离，必要时改用硬件 I²C 或数据就绪中断。
- 将 PID、传感器、执行器和通信参数集中到配置模块，减少散落在主程序中的魔法常数。
- 对共享变量使用明确的 `volatile` 声明、临界区或双缓冲交接，避免主循环和中断同时修改同一组参数。

### 4. 通信与故障安全

- 为蓝牙接收缓存增加长度边界检查、超长帧丢弃和重新同步机制。
- 在解析前检查帧类型、字段数量、数值范围和参数有效性。
- 增加蓝牙控制超时、MPU6050 读数异常、编码器异常和电池欠压处理。
- 建立 `DISARMED`、`ARMED`、`FALLEN` 和 `FAULT` 等运行状态，明确故障锁定和人工复位条件。
- 增加控制日志或遥测输出，便于分析角度、轮速、PWM 和故障发生时刻。

### 5. 寻迹功能扩展

寻迹目前没有硬件和固件实现。后续可在车体前下方安装多通道反射式传感器，完成逐通道标定后计算线路中心偏差，再将线路偏差转换为转向目标。

~~~text
p       = sum(i * 1000 * wi) / sum(wi)
e_line  = p - p_center
dv_ref  = sat(Kp_line * e_line + Kd_line * de_line / dt)
~~~

寻迹控制应作为速度和转向目标的外层输入，不能直接覆盖直立环的电机输出。还需要设计丢线、路口、停止线和全黑区域的状态判定。实现寻迹前，应先完成平衡车在低速运动状态下的姿态稳定和转向验证。

### 6. 实验与工程化完善

- 建立静态漂移、原地平衡、扰动恢复、速度跟踪和转向跟踪的标准测试流程。
- 用 RMSE、最大姿态偏差、扰动调节时间、速度误差、控制周期抖动和成功率评价改进效果。
- 保存每次实验的固件版本、PID 参数、电池电压、地面条件和原始日志。
- 补充硬件原理图、BOM、接线照片、调参记录和故障测试记录。
- 增加主机侧数据绘图或日志解析脚本，形成可重复的调参与验证流程。
